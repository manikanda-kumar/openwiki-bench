# Compact source-grounded documentation pilot

Create exactly two concise content pages for this repository, plus the index required by OpenWiki. Complete the normal OpenWiki lifecycle through openwiki_finish.

1. quickstart.md: installation and practical CLI examples; inputs, filtering, default/XML/Markdown output, line numbering and output files.
2. implementation.md: input traversal, hidden files and ignore handling, formatting, error handling, and a focused maintenance guide grounded in implementation and tests.

Aim for 400–600 words per content page. Treat source and tests as authoritative. Cite concrete source evidence for non-obvious technical claims; do not invent behavior or guarantees. State uncertainty when evidence is absent. Do not reproduce the entire README or exhaustive flag combinations.

Do not modify source files, document generated OpenWiki integration files, use subagents, or switch models. This is a bounded inference pilot, separate from the full benchmark cohort.
