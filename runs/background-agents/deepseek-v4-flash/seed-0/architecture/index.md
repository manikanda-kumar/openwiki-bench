# Files

- [Control Plane (Cloudflare Workers)](control-plane.md) - The control plane is the Cloudflare Workers service that fronts the Open-Inspect API — a fetch/scheduled/queue Worker entrypoint, a router with per-route authentication policies (user, service sig1, sandbox token), D1-backed stores fed through an instrumented ctx.db, and the SessionDO Durable Object that owns per-session runtime state and WebSockets.
- [System Architecture Overview](overview.md) - Open-Inspect is a single-tenant background coding agent system arranged in three tiers — web client, Cloudflare control plane (Durable Objects + D1), and sandbox data plane — plus three Hono bot workers, a @open-inspect/shared dependency root, and one canonical WebSocket prompt/event flow that every change must trace across service boundaries.
- [Persistence (D1, DO SQLite, R2, KV)](persistence.md) - How Open-Inspect stores state — one global D1 database behind instrumented SqlDatabase stores (session index, automations, secrets, environments, image builds, skills, users, integration settings, pull-request records), per-session synchronous SQLite inside each Session Durable Object, R2 for media, KV for caches, AES-256-GCM at-rest encryption, and D1 migrations in terraform/d1/migrations.
- [Sandbox Provider Abstraction and Infra Packages](sandbox-providers.md) - How the control plane abstracts Modal, Daytona, E2B, OpenComputer, and Vercel behind the SandboxProvider interface, how SandboxLifecycleManager makes spawn/restore/resume/snapshot/stop decisions, and how the infra packages build provider base images and templates.
- [Sandbox Runtime (in-sandbox Python agent)](sandbox-runtime.md) - How the Python sandbox-runtime package boots inside every provider sandbox — the supervisor lifecycle and restart policy, the bridge WebSocket to the control plane, OpenCode server management, repository sync, git signing and the credential helper, diff capture, managed-skills materialization, agent tools, and provider auth plugins.
- [Session Durable Object Runtime](session-do.md) - How each Open-Inspect session id maps to exactly one SessionDO Durable Object — a thin Cloudflare adapter that lazily initializes a per-activation composition root, an embedded SQLite schema shared with migration 31, internal HTTP route tables, a hibernation-aware WebSocket hub, a persisted-double alarm scheduler, and a message queue that dispatches prompts to the sandbox data plane.
- [Web Client (Next.js)](web-client.md) - The web client is a framework-free Next.js BFF that renders the session dashboard and live session view, proxies every authenticated API call to the control plane with a fresh sig1 web signature, forwards only Better Auth's opaque session cookie, and streams session state over an authenticated WebSocket whose token is minted by the control plane on demand.
